# Ankita Birthday Website ❤️

Open `index.html` in a browser to preview the website.

## Publish for free with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository, e.g. `ankita-birthday`.
3. Upload everything inside this folder (index.html, style.css, script.js, and the images folder).
4. In the repository go to Settings → Pages.
5. Under Build and deployment choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
6. GitHub will give you a public website URL. Send that link to Ankita.

## Important
The photos are stored locally in the `images` folder and are part of the website.
No server/database is required.
